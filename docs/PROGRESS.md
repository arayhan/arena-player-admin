Cross-agent communication file. Every agent reads this before working, appends after.
Format (caveman-compact): `[YYYY-MM-DD] [agent] [what] [reason]`

Agents: pm | lead | engineer | reviewer

**This file holds the current phase only.** Earlier entries move to `progress-archive/` when a
phase closes, so it never becomes a tax on every session — the web repo's version reached 44 KB
and roughly 11k tokens of context per agent per session before it was split.

What is currently **true** lives in [PRD.md](PRD.md), [architecture.md](architecture.md),
[database.md](database.md), and [PRODUCT.md](PRODUCT.md). This log records how it got that way,
not what the rules are. Do not distil "standing decisions" into here — that creates a fifth drift
surface, and this project has already paid for that three times.

**Cross-repo note:** decisions that change `arena-player-web` are recorded here _and_ land as a
gate file in `docs/tasks/`. A decision that exists only in a log the other repo never reads did
not happen.
