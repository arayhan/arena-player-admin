phase closes, so it never becomes a tax on every session — the web repo's version reached 44 KB
and roughly 11k tokens of context per agent per session before it was split.

not what the rules are. Do not distil "standing decisions" into here — that creates a fifth drift
surface, and this project has already paid for that three times.

gate file in `docs/tasks/`. A decision that exists only in a log the other repo never reads did
